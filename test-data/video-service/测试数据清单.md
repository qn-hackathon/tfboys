## 🎵 生成测试音频

### 方式 1: 使用 FFmpeg 生成简单音频

```bash
cd /workspace/test-data/video-service/

# 场景1音频 (3秒，440Hz 正弦波)
ffmpeg -f lavfi -i "sine=frequency=440:duration=3" \
  -ar 44100 -ac 2 -b:a 192k scene_1_audio.mp3 -y

# 场景2音频 (4秒，523Hz 正弦波)
ffmpeg -f lavfi -i "sine=frequency=523:duration=4" \
  -ar 44100 -ac 2 -b:a 192k scene_2_audio.mp3 -y

# 场景3音频 (5秒，659Hz 正弦波)
ffmpeg -f lavfi -i "sine=frequency=659:duration=5" \
  -ar 44100 -ac 2 -b:a 192k scene_3_audio.mp3 -y
```

### 方式 2: 使用七牛云 TTS 生成真实语音

参考项目中的 AI Service 代码：`backend/ai-service/app/services/voice_generator.py`

```python
from qiniu import Auth, put_data
import requests

# 配置
QINIU_ACCESS_KEY = "your-access-key"
QINIU_SECRET_KEY = "your-secret-key"
TTS_API_URL = "https://ai.qiniuapi.com/v1/audio/speech"

# 生成语音
texts = [
    "在一个阳光明媚的早晨，小明走在上学的路上",
    "突然，他发现前方的桥梁被大雨冲垮了",
    "小明决定绕道而行，最终按时到达了学校"
]

for i, text in enumerate(texts, 1):
    response = requests.post(
        TTS_API_URL,
        headers={
            "Authorization": f"Qiniu {QINIU_ACCESS_KEY}:{QINIU_SECRET_KEY}",
            "Content-Type": "application/json"
        },
        json={
            "text": text,
            "voice": "zh-CN-XiaoxiaoNeural"  # 或其他音色
        }
    )
    
    with open(f"scene_{i}_audio.mp3", "wb") as f:
        f.write(response.content)
    
    print(f"✅ scene_{i}_audio.mp3 已生成")
```

## 🚀 快速开始测试

### 步骤 1: 准备环境

```bash
# 确保在项目根目录
cd /workspace

# 进入 video-service 目录
cd backend/video-service

# 启动服务（使用 Docker Compose）
docker-compose up -d
```

### 步骤 2: 运行基础测试

```bash
# 运行项目自带的测试脚本
chmod +x test_video_service.sh
./test_video_service.sh
```

### 步骤 3: 准备测试数据 URL

修改 `/workspace/test-data/video-service/test_request.json`，将 `image_url` 和 `audio_url` 替换为实际可访问的 URL。

**选项 A**: 使用本地文件（仅限 Docker 环境内测试）

```json
{
  "image_url": "file:///workspace/test-data/video-service/scene_1.jpg",
  "audio_url": "file:///workspace/test-data/video-service/scene_1_audio.mp3"
}
```

**选项 B**: 使用在线 URL（推荐）

```json
{
  "image_url": "https://your-cdn.com/test/scene_1.jpg",
  "audio_url": "https://your-cdn.com/test/scene_1_audio.mp3"
}
```

### 步骤 4: 运行快速测试

```bash
cd /workspace/test-data/video-service
chmod +x quick_test.sh
./quick_test.sh
```

脚本会自动：
1. 检查服务健康状态
2. 验证测试数据文件
3. 创建视频合成任务
4. 轮询任务状态直到完成

### 步骤 5: 查看结果

任务完成后，按照脚本提示操作：

```bash
# 从 Docker 容器复制视频到本地
docker cp video-service:/tmp/tfboys/videos/test_task_001/final.mp4 ./output.mp4

# 查看视频信息
ffprobe output.mp4

# 播放视频（如果有播放器）
ffplay output.mp4
```
