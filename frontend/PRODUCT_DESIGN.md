# TFBoys AI - 前端产品设计文档

## 1. 产品概述

### 1.1 产品定位
TFBoys AI 是一款基于 AI 技术的小说自动转动漫视频工具,用户只需输入小说文本,系统即可自动生成配音动漫视频。

### 1.2 目标用户
- 小说作者:希望将作品可视化
- 内容创作者:需要快速制作短视频内容
- 动漫爱好者:想要看到文字转化为视频的过程

### 1.3 核心价值
- **自动化生成**:无需人工绘图和配音
- **角色一致性**:保证同一角色在不同场景的视觉一致性
- **快速产出**:几分钟内完成视频生成

#### 3.2.2 页面元素

#### 3.3.3 轮询机制

```javascript
// 每5秒轮询一次任务状态
useEffect(() => {
  const interval = setInterval(() => {
    fetchTaskStatus(taskId);
  }, 5000);
  
  return () => clearInterval(interval);
}, [taskId]);
```

状态映射:
- `pending` → 显示 "等待处理"
- `analyzing` → 显示 "文本分析中"
- `generating_images` → 显示 "图像生成中"
- `generating_audio` → 显示 "配音生成中"
- `synthesizing_video` → 显示 "视频合成中"
- `completed` → 显示播放器和下载按钮
- `failed` → 显示错误信息

#### 3.4.4 实时更新

对于"进行中"状态的任务,启用轮询:
```javascript
// 每10秒轮询一次进行中的任务
useEffect(() => {
  const processingTasks = tasks.filter(t => t.status === 'processing');
  
  const interval = setInterval(() => {
    processingTasks.forEach(task => {
      refreshTaskStatus(task.task_id);
    });
  }, 10000);
  
  return () => clearInterval(interval);
}, [tasks]);
```

## 9. 错误处理

### 9.1 网络错误

```typescript
// 全局错误拦截器
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 429) {
      message.error('请求过于频繁,请稍后再试');
    } else if (error.response?.status >= 500) {
      message.error('服务器错误,请稍后重试');
    } else {
      message.error(error.response?.data?.message || '请求失败');
    }
    return Promise.reject(error);
  }
);
```
