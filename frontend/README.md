## 🎯 产品核心

### 产品定位
小说文本自动生成动漫视频的 Web 应用

### 核心价值
- 🤖 **自动化创作** - 将文字转化为视觉内容
- 🎭 **角色一致性** - AI 保证角色视觉一致性
- ⚡ **快速生成** - 全自动流程，用户只需等待
- 🎨 **风格可定制** - 支持多种视频风格

### 目标用户
- 📚 小说作者 - 为作品制作宣传视频
- 🎬 内容创作者 - 快速生成视频内容
- 🌟 二次元爱好者 - 小说片段可视化
