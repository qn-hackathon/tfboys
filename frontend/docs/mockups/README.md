# 原型图说明

本目录包含 TFBoys AI 前端的原型图设计。**所有原型图都包含完整的应用布局结构**（顶部栏 + 侧边栏 + 内容区域）。

## 整体布局结构

所有页面都采用统一的三栏布局：

```
┌─────────────────────────────────────┐
│  顶部栏 (Header)                    │
│  Logo | 额度 | 用户 | 模式 | 通知   │
├──────────┬──────────────────────────┤
│          │                          │
│ 侧边栏   │  内容区域                 │
│          │                          │
│ 📹 视频   │  (根据选择动态变化)       │
│   生成   │                          │
│          │                          │
│ 📋 我的   │                          │
│   任务   │                          │
│          │                          │
└──────────┴──────────────────────────┘
```

**顶部栏**：Logo、额度显示、用户菜单、夜间模式切换、系统通知  
**侧边栏**：视频生成、我的任务（含任务数量角标）  
**内容区域**：根据侧边栏选择动态展示不同页面内容

**我的任务页面原型**（尺寸：1400x900px）

展示所有视频生成任务的列表页面，包含完整的三栏布局结构。

**完整布局**：
- ✅ **顶部栏**：完整展示所有元素
- ✅ **侧边栏**：我的任务（选中蓝色高亮）、视频生成，任务角标显示 3

**内容区功能**：
- 🔍 筛选和搜索栏
  - Tab 筛选：全部（选中）/进行中/已完成/失败
  - 搜索框：🔍 搜索任务...
- 📋 任务卡片展示
  - **进行中任务**：
    - 任务标题 + 蓝色"进行中"标签
    - 状态文字：图像生成中
    - 进度条：60% 蓝色填充
    - 已处理场景数：6 / 10
    - 预计剩余时间：2 分钟
    - 操作：查看详情、取消任务
  - **已完成任务**：
    - 视频缩略图（120x90）
    - 任务标题 + 绿色"已完成"标签
    - 视频信息：时长、场景数、文件大小
    - 创建时间
    - 操作：预览（蓝色主按钮）、下载、删除
  - **失败任务**：
    - 任务标题 + 红色"失败"标签
    - 错误原因（红色文字）
    - 创建时间
    - 操作：重试（蓝色主按钮）、删除
- 📄 分页组件
  - 上一页、1 / 3、下一页
