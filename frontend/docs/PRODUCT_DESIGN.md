# 一、产品经理产出

## 1. 产品概述

### 1.1 产品定位

TFBoys AI 是一款通过小说文本自动生成动漫视频的 Web 应用。用户输入小说内容，系统自动分析场景、生成图像、配音，并合成为完整的动漫视频。

### 1.2 目标用户

- **小说作者**：希望为作品制作宣传视频
- **内容创作者**：需要快速生成视频内容
- **二次元爱好者**：想将喜欢的小说片段可视化

### 1.3 核心功能

1. **文本输入与解析**
   - 支持直接输入文本
   - 支持上传文件 (.txt)
   - 支持粘贴 URL 自动抓取内容

2. **视频参数配置**
   - 多种视频风格选择（古风、现代、动漫、奇幻、3D 卡通）
   - 配音类型选择（女声、男声、童声）
   - 分辨率选择（1080p、720p）

3. **实时预览与进度监控**
   - 集成视频播放器，即时预览生成结果
   - 实时显示生成进度条和处理状态
   - 视频切片轮播，快速浏览关键场景
   - 模板视频轮播，帮助用户了解风格效果

4. **视频切片功能**
   - 自动将生成的视频按场景切片
   - 使用 Carousel 组件展示所有切片
   - 点击切片可跳转到对应场景
   - 支持横向滚动浏览所有场景

5. **视频操作**
   - 重新生成视频（调整参数后）
   - 下载视频文件到本地
   - 下载单个切片
   - 生成分享链接

5. **任务管理**
   - 实时任务进度监控
   - 任务列表展示
   - 任务筛选与搜索
   - 任务预览与删除

### 1.4 核心价值

- **自动化创作**：将文字转化为视觉内容，降低视频制作门槛
- **角色一致性**：AI 保证角色在不同场景中的视觉一致性
- **快速生成**：全自动流程，用户只需等待结果
- **风格可定制**：支持多种视频风格和参数配置

## 2. User Story

### 2.1 视频生成页面

**作为一个内容创作者，我希望能够快速将小说文本转化为视频，并实时预览生成效果，以便在社交媒体上分享。**

**场景**：用户打开应用后直接进入视频生成页面，左侧为输入配置区，右侧为预览展示区

**用户操作流程**：

1. **浏览模板视频（可选）**
   - 用户可以先在右侧底部的轮播组件中浏览模板视频
   - 点击模板缩略图，在播放器中预览该模板效果
   - 了解不同风格的视频呈现方式
   - 为后续选择风格提供参考

2. **输入小说内容**
   - 在左侧输入区域，用户可以选择三种方式输入内容：
     - 直接在文本框中输入或粘贴
     - 上传本地 .txt 文件
     - 粘贴小说网站 URL，系统自动抓取
   - 系统实时显示字数统计
   - 如果字数超出限制，显示红色警告提示

3. **配置视频参数**
   - 选择视频风格（古风、现代、动漫、奇幻、3D 卡通）
   - 选择配音类型（女声、男声、童声）
   - 选择视频分辨率（1080p、720p）
   - 系统实时显示预计生成时间

4. **生成视频并实时查看进度**
   - 点击左侧底部的"生成视频"按钮
   - 系统验证输入（字数、风格等）
   - 开始生成，右侧播放器下方显示进度条
   - 进度条实时更新百分比和当前处理状态
   - 用户可以在当前页面等待生成完成

5. **预览和操作生成的视频**
   - 生成完成后，视频自动在右侧播放器中加载
   - 播放器下方自动显示视频切片轮播（Carousel）
   - 用户可以：
     - 播放预览完整视频
     - 在切片轮播中浏览所有场景
     - 点击切片缩略图快速跳转到对应场景
     - 左右滑动浏览更多切片
   - 操作按钮变为可用状态：
     - **重新生成**：如果不满意，可以调整参数重新生成
     - **下载视频**：下载生成的视频文件到本地
     - **分享视频**：生成分享链接，复制后分享给他人

**验收标准**：
- ✅ 左右分栏布局清晰，操作流畅
- ✅ 支持三种输入方式
- ✅ 实时字数统计和验证
- ✅ 所有配置项都有默认值
- ✅ 模板视频轮播可以正常预览
- ✅ 生成进度实时显示，状态文字准确
- ✅ 视频生成完成后自动在播放器中加载
- ✅ 视频切片自动生成并显示在 Carousel 中
- ✅ 点击切片可跳转到对应场景
- ✅ 切片轮播支持左右滑动
- ✅ 操作按钮根据状态正确启用/禁用
- ✅ 下载和分享功能正常工作

### 2.2 我的任务页面

**作为一个用户，我希望能够查看所有视频生成任务的状态，以便了解进度和管理任务。**

**场景**：用户点击侧边栏"我的任务"查看所有任务

**用户操作流程**：

1. **查看任务列表**
   - 显示所有任务卡片，包含：
     - 任务标题（小说前 20 字）
     - 当前状态（进行中/已完成/失败）
     - 进度条和百分比（进行中的任务）
     - 创建时间
     - 操作按钮

2. **筛选和搜索**
   - 按状态筛选：全部/进行中/已完成/失败
   - 按关键词搜索任务
   - 按时间排序

3. **任务操作**
   - **进行中的任务**：
     - 实时更新进度（每 5 秒刷新）
     - 可以取消任务
   - **已完成的任务**：
     - 点击预览视频
     - 下载视频文件
     - 删除任务
   - **失败的任务**：
     - 查看失败原因
     - 重试生成
     - 删除任务

4. **视频预览**
   - 点击"预览"按钮，在弹窗中播放视频
   - 弹窗中显示完整的视频切片轮播
   - 支持点击切片跳转到对应场景
   - 支持下载完整视频和单个切片
   - 支持生成分享链接

**验收标准**：
- ✅ 任务列表实时更新
- ✅ 支持多种筛选和搜索方式
- ✅ 不同状态的任务显示不同操作按钮
- ✅ 失败任务可以重试
- ✅ 视频预览流畅，支持完整播放控制
- ✅ 视频切片完整显示，可点击跳转
- ✅ 切片轮播支持横向滚动

# 二、设计师产出

## 4. 设计系统

### 4.1 技术栈

**UI 组件库**: [shadcn/ui](https://ui.shadcn.com/)
- 基于 Radix UI 的高质量组件库
- Blue 主题变体
- 完全可定制的组件
- 支持无障碍访问

**CSS 框架**: [Tailwind CSS](https://tailwindcss.com/)
- 实用优先的 CSS 框架
- 高度可定制
- 与 shadcn/ui 完美集成

### 4.2 设计原则

1. **简洁性**：界面简洁，减少用户认知负担
2. **一致性**：保持视觉风格和交互方式的一致性
3. **响应式**：适配不同屏幕尺寸
4. **可访问性**：支持键盘导航和屏幕阅读器
5. **反馈性**：及时的视觉反馈和状态提示

## 5. 线框图

### 5.1 整体布局结构

应用采用经典的三栏布局：**顶部栏 + 侧边栏 + 内容区域**

```
┌─────────────────────────────────────────────────────────────────┐
│  TFBoys AI    |  额度: 100  👤 用户名 ▼  🌙  🔔              │ ← 顶部栏
├──────────┬──────────────────────────────────────────────────────┤
│          │                                                      │
│  📹 视频  │                                                      │
│    生成   │                                                      │
│          │                    内容区域                           │
│  📋 我的  │                                                      │ ← 侧边栏 + 内容区
│    任务   │                 (根据选择的页面动态变化)              │
│          │                                                      │
│          │                                                      │
└──────────┴──────────────────────────────────────────────────────┘
```

#### 5.1.1 顶部栏 (Header)

**左侧**：
- Logo + 产品名称：TFBoys AI

**右侧**（从左到右）：
1. **额度显示**：`额度: 100 分钟` 或 `剩余: 5 个视频`
2. **用户菜单**：
   - 用户名称 + 下拉图标
   - 点击展开下拉菜单：
     - 个人设置
     - 退出登录
3. **夜间模式切换**：🌙 / ☀️ 图标切换
4. **系统通知**：🔔 图标
   - 显示未读通知数量角标
   - 点击展开通知列表

#### 5.1.2 侧边栏 (Sidebar)

导航菜单（垂直排列）：

1. **📹 视频生成**（主页面）
   - 默认选中状态
   - 点击进入视频生成页面

2. **📋 我的任务**
   - 点击进入任务列表页面
   - 显示进行中任务数量角标

**设计细节**：
- 侧边栏宽度：240px
- 菜单项高度：56px
- 选中状态：蓝色高亮背景
- 鼠标悬停：浅色背景

#### 5.1.3 内容区域 (Main Content)

根据侧边栏选择的菜单动态展示不同内容：
- 选择"视频生成" → 显示视频生成页面
- 选择"我的任务" → 显示任务列表页面

| 背景色 (Background) | `hsl(0, 0%, 100%)` | 白色 |
| 文字色 (Foreground) | `hsl(222.2, 84%, 4.9%)` | 深蓝灰 |

**主字体**: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto

| 用途 | 大小 | 对应 |
