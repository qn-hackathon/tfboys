## 🎯 用户核心流程

### 流程 1: 创建视频任务
1. 访问首页
2. 点击"开始创作"
3. 选择输入方式(文本/文件/URL)
4. 输入小说内容
5. 配置视频风格和参数
6. 提交生成

### 流程 2: 监控任务进度
1. 自动跳转任务列表页
2. 查看任务状态和进度
3. 等待任务完成(自动刷新)
4. 收到完成通知

### 流程 3: 预览和下载视频
1. 点击"查看视频"
2. 在线播放预览
3. 查看场景时间轴
4. 下载视频或生成分享链接

### 流程 4: 管理历史任务
1. 进入任务历史页
2. 搜索或筛选任务
3. 批量操作(删除)
4. 重新下载或查看任务

## ⚡ 技术实现要点

### 前端技术栈
- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **UI组件库**: Ant Design 5
- **路由**: React Router v6
- **HTTP客户端**: Axios
- **视频播放器**: Video.js
- **状态管理**: Zustand(可选)

### 性能优化
- 路由懒加载(代码分割)
- 图片懒加载和WebP格式
- 智能轮询(根据任务状态调整频率)
- 页面可见性检测(隐藏时停止轮询)

### 安全性
- XSS防护(React自动转义)
- CSRF防护(Token验证)
- 文件上传安全(类型和大小限制)
- 输入验证(前后端双重验证)

## 📝 使用说明

### 查看原型图

**方法 1:浏览器查看**
```bash
# 在浏览器中直接打开 SVG 文件
open frontend/docs/mockups/01-home-page.svg
```

**方法 2:在 GitHub 中查看**
- GitHub 支持 SVG 文件的在线预览
- 点击上方的原型图链接即可查看

**方法 3:在设计工具中编辑**
- SVG 文件可在 Figma、Sketch、Adobe XD 等工具中导入编辑
- 可根据需要调整颜色、布局、文字等元素

### 导出为图片

如需导出为 PNG/JPG 格式:

**使用浏览器**:
1. 在浏览器中打开 SVG 文件
2. 使用浏览器开发者工具截图
3. 或使用浏览器扩展进行截图

**使用命令行工具**:
```bash
# 使用 ImageMagick
convert mockups/01-home-page.svg mockups/01-home-page.png

# 使用 Inkscape
inkscape mockups/01-home-page.svg --export-png=mockups/01-home-page.png
```
