## 📝 使用说明

### 查看原型图

**方法 1:浏览器查看**
```bash
# 在浏览器中直接打开 SVG 文件
open frontend/docs/mockups/01-home-page.svg
```

**方法 2:在 GitHub 中查看**
- GitHub 支持 SVG 文件的在线预览
- 点击上方的原型图链接即可查看

**方法 3:在设计工具中编辑**
- SVG 文件可在 Figma、Sketch、Adobe XD 等工具中导入编辑
- 可根据需要调整颜色、布局、文字等元素

### 导出为图片

如需导出为 PNG/JPG 格式:

**使用浏览器**:
1. 在浏览器中打开 SVG 文件
2. 使用浏览器开发者工具截图
3. 或使用浏览器扩展进行截图

**使用命令行工具**:
```bash
# 使用 ImageMagick
convert mockups/01-home-page.svg mockups/01-home-page.png

# 使用 Inkscape
inkscape mockups/01-home-page.svg --export-png=mockups/01-home-page.png
```
